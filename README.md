# automatic-carnival

業務改善・自動化の検証用リポジトリです。

## 目的

このリポジトリでは、社内業務の効率化や自動化に関するコード、設定、ドキュメントを整理・検証します。

## 想定する内容

- Pythonによる業務自動化
- Excel / VBA関連の補助ツール
- Google Apps Script
- AI活用のためのプロンプトや設定
- 社内業務フローの検証用ドキュメント

## 運用方針

- 本番運用前に必ず内容をレビューする
- 変更履歴はGitで管理する
- 用途ごとにフォルダを分ける
- 重要な変更はPull Requestを利用する

## セキュリティ上の注意

このリポジトリは現在Publicです。

以下の情報は保存しないでください。

- 顧客・入居者・オーナー等の個人情報
- 物件に関する非公開情報
- 契約書や社内機密資料
- パスワード
- APIキー
- アクセストークン
- その他の認証情報

業務利用する場合は、Private Repositoryへの切り替え、または別途Private Repositoryを作成して運用することを推奨します。
