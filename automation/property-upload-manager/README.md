# 物件情報アップロード管理ツール（Prototype）

海外商事株式会社の「物件情報アップロードマスター.xlsx」を正本として扱い、公開前の入力確認・3段階承認・No-Go判定を補助するデスクトップツールです。

## 設計方針

- WordPressへの公開操作は行いません。
- 元Excelを直接上書きしません。「別名で保存」でレビュー済みコピーを作ります。
- 元ブックに含まれる x14 形式のプルダウン入力規則を壊さないため、書込時はシートXMLの対象セルのみを更新します。
- Public GitHubには実在物件データ・顧客情報・認証情報を置かないでください。

## 画面

1. 物件一覧: ID、物件名、公開状態、指摘数
2. 入力・編集: 物件マスターの主要入力欄
3. 自動チェック: ERROR/WARNと公開判定
4. 承認: 業務確認、技術確認、公開承認と各日付

## 主な自動チェック

- 物件IDの未入力・重複（編集後も一覧全体を再検証）
- Excel必須16項目の未入力
- 選択肢外の値
- 賃料・敷礼・面積の型と範囲
- 郵便番号形式
- URL形式
- 日英ペアの片側未入力
- 日英整合「要修正」
- 承認日漏れ、差戻し
- 承認未完了での公開段階
- 公開中の公開日／公開URL不足
- 募集停止・契約済なのに公開中

## 起動

```bash
pip install openpyxl
python app.py
```

## 人による確認が必要な事項

- 元資料そのものが正しいか
- 日本語と英語の意味・契約条件が実質的に一致しているか
- 画像・間取図の著作権／利用許諾
- WordPressプレビュー、スマホ表示、検索、フォーム実送信
- バックアップ／復旧可能性
- 最終Go/No-Go判断

## ID未入力行の取扱い

- IDがなくても、他の項目に値がある行は一覧に表示し、ID_MISSINGとして検出します。
- 全項目が空欄（空白文字のみを含む）の行は除外します。0は入力値として扱います。
- 「入力・編集」の物件ID欄で補完し、「変更を一時反映」で検証してください。
- 空欄IDは一覧でExcel行番号を表示します。編集・保存先も行番号で識別します。
- 重複IDは前後の空白を除いて比較し、Excel数値IDと同じ文字列IDも重複として検出します。
- ID未入力・重複がある物件はNO-GOです。修正途中のコピーは別名保存できます。

## 回帰テスト

リポジトリのルートから実行します（GUI表示不要、架空データのみ）。

```bash
python -m unittest discover -s automation/property-upload-manager/tests -v
```

ID未入力・空白行・重複・画面ハンドラーでの補完と再検証、別名保存時の標準／x14入力規則と元ファイルの保持を確認します。
