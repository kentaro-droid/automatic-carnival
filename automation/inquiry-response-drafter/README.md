# Inquiry Response Drafter

外国人向け高級賃貸の問い合わせに対して、日本語・英語の返信ドラフトを作成するための検証プロジェクトです。

## 目的

- 返信品質の標準化
- 担当者ごとの表現差の縮小
- 初動返信の作成時間短縮
- 日本語・英語の期待値管理の統一

## 前提

このリポジトリはPublicのため、実在する顧客・入居者・オーナー・物件の非公開情報は入力・保存しないでください。

検証時は必ず架空データまたは匿名化済みデータを使用します。

## 入力項目

- inquiry_language: `ja` または `en`
- customer_name: 架空名または匿名化名
- property_name: 公開して問題のない物件名、または架空名
- request_type: viewing / availability / application / general
- move_in_date: 入居希望日
- budget: 予算
- notes: 社内用の補足（顧客向け返信には含めません）

## 出力

- 件名
- 日本語返信案
- 英語返信案
- 社内確認事項

顧客向け返信と社内確認事項は別々の欄に表示します。顧客向け返信は編集可能で、
通常の **Copy to Clipboard** は編集後の顧客向け返信（件名を含む）だけをコピーします。
社内チェックリストと内部メモは読み取り専用の社内欄で確認してください。

`generate_response()` は `ResponseDraft` を返します。
`customer_reply` は顧客向け本文、`internal_checklist` は社内チェックリストと内部メモです。
この変更に合わせて呼び出し側も各フィールドを使ってください。
CLIのサンプル表示は引き続き両方を明示した見出し付きで出力します。

## 回帰テスト

このフォルダで `python -m unittest discover -v` を実行してください。
日本語・英語、内部メモあり・なし、担当者による本文修正、再生成、クリア、
入力検証を確認します。画面コールバックとクリップボード呼び出しは
ヘッドレスの代替オブジェクトで検証します。実際の画面・OSクリップボードは
`SETUP_WINDOWS.md` の手順で確認してください。

## 運用上の注意

- 自動生成文はそのまま送信せず、担当者が最終確認する
- 空室、賃料、契約条件、審査条件は必ず最新情報を確認する
- 法的・契約上の確約表現を避ける
- 個人情報、APIキー、認証情報はGitHubに保存しない
